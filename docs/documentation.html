1. System Overview

HMS Core is a comprehensive, premium Hospital Management System designed to digitize and streamline clinical operations. It provides a centralized platform for managing patients, appointments, medical records, billing, pharmacy, diagnostics, facility management, staffing, inventory, and blood bank operations.

Key Features

  • Real-time clinical operations dashboard with KPI monitoring
  • Complete patient lifecycle management (registration → discharge)
  • Appointment scheduling with live medical queue
  • Electronic Medical Records (EMR) with diagnosis and prescription tracking
  • Revenue cycle management with invoice generation
  • Pharmacy stock management with batch tracking
  • Diagnostic lab test ordering and status tracking
  • Bed/facility management with real-time availability
  • Staff/HR management with shift scheduling
  • Inventory and supply chain management
  • Blood bank with group-wise unit tracking
  • Fully responsive design (mobile, tablet, desktop)
  • Light/Dark mode theme toggle with persistence

Architecture

The application follows a component-based architecture with lazy-loaded pages for optimal performance. All pages are wrapped in a ProtectedRoute component that redirects unauthenticated users to the login page.

DirectoryPurpose
src/pages/Page-level components (lazy loaded)
src/components/Layout/Layout shell (Sidebar, Navbar, Layout)
src/components/Auth/Authentication (ProtectedRoute)
src/components/UI/Reusable UI components (Modal)
src/context/Global state via Context API

3. Authentication

The system uses a secure login flow with session persistence via localStorage. All application routes are protected and require authentication.

Login Credentials

FieldValue
UsernameCreate your own account

Features

  • Password visibility toggle (eye icon)
  • Session persistence across browser refreshes
  • Protected route system with redirect to login
  • Toast notifications for login success/failure

4. Dashboard — Command Center

The main dashboard provides a real-time overview of hospital operations through KPI cards, department performance metrics, and a live medical queue.

Components

  • Stat Cards: Active Admissions, Critical Alerts, Total Patients, Monthly Revenue — each with trend indicators
  • Department Performance: Visual analytics placeholder for charting integration
  • Live Medical Queue: Real-time appointment feed with patient names, doctors, and statuses

5. Patient Directory

Comprehensive patient registry with full CRUD operations. Track patient demographics, blood groups, visit history, and admission status.

Features

  • Add new patients via modal form
  • Search and filter patient records
  • Track admission status (Inpatient / Outpatient)
  • Auto-generated patient IDs (P-XXX format)

6. Scheduling & Appointments

Schedule and manage patient appointments with doctor assignment, time slots, and status tracking.

Features

  • Create appointments with patient, doctor, time, and type
  • Status tracking: Scheduled, In Progress, Completed
  • Integration with Dashboard's live medical queue

7. Electronic Medical Records

Digital medical record management with diagnosis and prescription tracking.

Features

  • Create clinical records with diagnosis and prescriptions
  • Auto-generated Clinical IDs and EMR IDs
  • Link records to patients and doctors

8. Revenue Cycle & Billing

Invoice management system for tracking patient billing, payment methods, and outstanding balances.

Features

  • Generate invoices linked to patients
  • Track payment status (Paid / Pending)
  • Payment method tracking (UPI, Cash, Card)

9. Pharmacy Management

Medicine inventory tracking with batch management, stock levels, and expiry monitoring.

Features

  • Track medicine stock with batch numbers
  • Monitor expiry dates
  • Stock status indicators (In Stock / Low Stock)

10. Diagnostics & Lab

Laboratory test ordering and result management system.

Features

  • Order lab tests linked to patients and doctors
  • Status tracking: Pending Approval → Processing → Complete
  • Auto-generated Lab IDs

11. Facility Management

Bed and ward management with real-time availability tracking.

12. Human Capital

Staff and HR management including doctor, nurse, and support staff tracking with shift scheduling.

Features

  • Staff directory with role and department assignment
  • Shift management (Morning / Evening / Night)
  • Status tracking (Active / On Leave)

13. Intelligence & Reports

Analytics and reporting module for generating hospital performance insights.

14. Hospital Logistics

Inventory and supply chain management for tracking hospital supplies, PPE, surgical equipment, and consumables.

Features

  • Track items with stock levels and consumption rates
  • Status indicators: In Stock, Low Stock, Critical
  • Reorder functionality per item
  • Category-based organization (PPE, Medical, Surgical, General)

15. Emergency Blood Bank

Real-time blood unit availability tracking with donation and request activity logs.

Features

  • Card-based view for all 8 blood groups (A+, A-, B+, B-, AB+, AB-, O+, O-)
  • Status: Stable, Low, Critical with color-coded indicators
  • Daily stock trend tracking
  • Recent activity log (Donations & Requests)

17. Theming & Dark Mode

The application supports both light and dark themes with a toggle button in the navbar. Theme preference is persisted in localStorage.

Implementation

  • CSS variables defined in :root for light mode (default)
  • [data-theme="dark"] selector overrides all variables for dark mode
  • Theme toggle sets data-theme attribute on <html> element
  • Smooth transitions on all color changes
